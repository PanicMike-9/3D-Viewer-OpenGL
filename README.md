# 3D Object Viewer

An OpenGL project build in C++ to explore 3D rendering, shaders, camera systems and 3D model loading.

## Minimum Requirements

- C++ 17 or above
- OpenGL 4.1 
- GLFW
- GLAD
- GLM Math Library
- CMake
- MSVC or MinGW

## Build the project

```bash
   git clone https://github.com/PanicMike-9/3D-Viewer-OpenGL.git
```
## Generate files

```bash
   cmake -S . -B build
   cmake --build build

   ./build/Debug/app.exe
```
