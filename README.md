# 3D Object Viewer

An OpenGL project built in C++ to explore 3D rendering, shaders, camera systems and 3D model loading.

## Minimum Requirements

- C++ 17 or above
- OpenGL 4.1 
- GLFW
- GLAD
- GLM Math Library
- CMake 4.2.0
- MSVC or MinGW

## Generate & Build

```bash
   git clone https://github.com/PanicMike-9/3D-Viewer-OpenGL.git
   cd 3D-Viewer-OpenGL
```
```bash
   cmake -S . -B build
   cmake --build build

   ./build/Debug/app.exe
```
